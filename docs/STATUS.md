# 開發狀態與待完成範圍

本專案的目標是完整《MapChart ∞》。目前上傳的是開發中的程式，指令清單與測試結果可在 GitHub 檢查。

## 已實作並持續測試

- 四級行政圖層、獨立／嵌套層、跨區共管、交集面積自動綁定與可選的子區控制權自動匯總。
- 點選地塊、顏色、旗幟、控制方與多個宣稱方、關係鏈、跨圖層搜尋及定位、地塊名稱及代碼；手繪範圍切分地塊。
- 手繪線段及平滑曲線，可在介面設定並修改顏色、粗細、虛線、不透明度與柔性效果；可刪除及復原。
- 畫面與元件編輯、資料綁定、按鈕動作、指令腳本保存與預覽執行。
- 部隊資料及編組、手動外交操作（邀請與申請入盟、藩屬、內戰）、資料型模組、事件與時間推進。
- 圖片、GeoJSON、HOI4 地圖 ZIP 的部分匯入，及本機世界保存與匯出。
- AI 提示詞、外部 HTTPS 接口與變更預覽，提供自己的模型及金鑰後可使用。
- iOS 直向／橫向佈局、雲端編譯與未簽署 IPA 打包。

## 尚待完成

- 使用者指定的 1,000 項完整功能。已註冊數量由 `docs/command-catalog.json` 自動產生。
- 2026 年完整一／二級行政地塊、旗幟及未受承認國家選項。
- 1816 年完整行政地圖與到冷戰的歷史邊界、旗幟及可驗證事件。
- 《1931：長路漫漫》與《風暴前夕》劇本、指定東亞至南亞地塊與各方勢力資料。
- 《政治專精》《崇拜系統》《軍事專精》《地下戰爭》《系統工程》《強國遊戲》《雜項包》《更好的地圖繪製系統》的完整規則與內容。部分模組目前提供基礎資料操作。
- 完整經濟、科技樹、軍事推演、地圖動畫、曲線節點拖曳與單條線的局部調色、雲端同步及更多 Paradox 遊戲格式。
- 實體 iPhone 安裝、效能與所有功能的端到端驗證。
