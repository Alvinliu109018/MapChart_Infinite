# MapChart_Infinite
## 開發中的 iOS 版本

目前提供地圖核心、手機介面、UI 和腳本編輯器，以及 GitHub Actions 未簽署 IPA 打包。功能與資料的實作狀態見 [開發狀態](docs/STATUS.md)。接口、資料結構和已註冊指令見 [接口文件](docs/API.md)，AI 提示詞見 [提示詞](docs/AI-prompts.md)。

在 Actions 選擇 **Build iOS development package**，從成功的執行紀錄下載 `MapChartInfinity-development-unsigned`。下載的 ZIP 內含未簽署 `.ipa`，可用符合自己裝置的工具與憑證簽署安裝。
